# 색의 선명함 연구 — "왜 내 색은 흐린가"

## 자료
- **Lospec 공개 팔레트 7종(270색):** Endesga 32, Resurrect 64, AAP-64, PICO-8, Sweetie 16, DawnBringer 32, Apollo.
- **비교 대상:** Mojang 공식 갑옷·몹 텍스처, 그리고 내 갑옷·보스.
- **측정:** OKLCH(명도 L 0~100, 채도 C ×100)로 쟀다. 도구: scratchpad colorstudy.py. 같은 기능을 `atelier/analyze.py`의 palette 항목에서도 볼 수 있다.

## 검증된 팔레트의 램프 구조
| 팔레트 | 채도 중앙값 | 무채색 비율 | 대표 램프 |
|---|---|---|---|
| Endesga 32 | 10.2 | 28% | 9단 L 43→82, 채도 어둠 7.5 / 중간 13.8 / 밝음 7.2, 색상 +29° |
| Resurrect 64 | 11.4 | 27% | 12단 L 38→88, 채도 10.1 / 19.4 / 6.8, +27° |
| AAP-64 | 8.0 | 41% | 8단 L 43→82, 6.8 / 8.9 / 6.6, +12° |
| PICO-8 | 12.7 | 31% | 3단 L 42→74, 13.1 / 25.4 / 17.2, +7° |
| DawnBringer 32 | 8.8 | 34% | 6단 L 40→84, 6.6 / 16.0 / 7.3, +34° |

규칙:
1. **채도는 중간 톤에서 가장 높다**(중간 14~25). 어둠과 밝음은 그 55~65%(6~10)다. 색의 정체성은 중간 톤이 책임진다.
2. **램프 하나의 명도 폭은 30~50**이다(38→88 등). 폭이 좁으면 흐리게 보인다.
3. **밝은 쪽으로 갈수록 색상을 +10~35° 이동한다**(대체로 따뜻한 쪽).
4. 무채색은 27~41%다. 무채색을 쓸 때는 밝기를 확실히 정한다.

## 진단: 흐림 = 채도도 낮고 명도도 어중간한 것
- 바닐라는 **무채색이면 아주 밝거나(철 L 84) 아주 어둡게 확실히** 정하고(네더라이트), **색이 있으면 채도 12 이상**으로 간다.
- 피의 군주 v4는 채도 5에 명도 34라서, 색 있는 갑옷도 밝은 철도 아닌 "색이 빠진 어두운 회보라"였다.
- 원인은 램프의 기준색 자체가 회색빛(C 약 0.05)인데, 그 채도를 램프 전체에 그대로 썼기 때문이다.

## 규칙(엔진에 반영: `fineRamp(base, { chroma })`)
1. 재질 램프는 **중간 톤 채도를 직접 정한다**(OKLCH C 0.10~0.19). 어둠·밝음은 자동으로 55~65%가 된다.
2. **유색 재질의 면적 가중 채도는 11 이상**(바닐라 12~15)이다. 무채색이면 L 75 이상이나 40 이하로 확실히 정한다.
3. **재질 하나의 명도 폭(p5~p95)은 30 이상**이다.
4. **두 직업이 같은 색상 계열이면 정체성이 무너진다.** 주 재질의 색상을 60° 이상 떨어뜨린다(피의 군주 = 핏빛 자두 약 350°, 폴터가이스트 = 보라 약 300°에 민트 강조).
