# 레퍼런스 연구: 브랜드 마크 · 앱 아이콘 · 아이콘 세트

측정 항목:
- **box:** 내용 bbox / 캔버스(%)
- **thick:** 획 두께(%)
- **shapes/holes:** 잉크 덩어리 수 / 닫힌 빈 공간 수
- **sym:** 뒤집기 IoU
- **mush16/24/32:** 그 크기로 렌더했을 때 잉크 중 회색 픽셀 비율. 0.25 이하는 선명, 0.5 이상은 뭉갬.

출처:
- Wikimedia Commons: Mitsubishi, CBS Eye, Deutsche Bank, 올림픽 오륜, AIGA/DOT Toilets(퍼블릭 도메인). 로고는 상표권이 있으므로 원리만 쓴다.
- 아이콘 세트: Tabler(MIT), Feather(MIT), Lucide(ISC), Material Symbols(Apache-2.0), Fluent(MIT).
- 앱 아이콘: GNOME 앱 아이콘 3종.
- 가이드라인: Apple HIG, GNOME HIG.

## 1. 사례별 핵심
- **Mitsubishi:** 60° 마름모 모듈 하나를 120°씩 회전한다(비율 √3). 1색이고 mush16 0.31. 틈이 두 번째 형상(Y)을 만든다.
- **CBS Eye:** 원과 원호뿐이다. 렌즈 93%×57.8%, 동공 53%, 흰 띠 2.3%(틈의 하한). 1색, mush16 0.25.
- **Deutsche Bank:** 테 14.2%와 54° 사선(수직 두께 21.8 = 테)으로 요소 2개, 획 두께 하나다. 180° 회전 대칭, mush16 0.23.
- **올림픽 오륜:** 획/지름 9.6%, 틈 = 획. 모듈 체계는 좋다. 다만 5색에 얇고 가로로 길어서 mush16 0.85(반례).
- **AIGA Toilets:** 사지 폭 5.2~6.5%로 통일, 머리 지름 11.3%. 다리 사이 틈이 1~1.5%라 24px 이하에서 막힌다(mush24 0.55).
- **Tabler:** 24 그리드, 획 2(8.33%), 바깥 모서리 2, 안쪽 1, bbox 83.6%. 원래 크기인 24px에서 mush 0.05~0.18.
- **Feather → Lucide:** Feather는 패딩이 섞여 있다(91.8~100%). Lucide는 83.6~91.8%로 정리했다.
- **Material Symbols:** 획 1.5 @24. 키라인 실측값: 원형 20, 사각 18, 세로형 16×20.
- **Fluent:** 획 1.5에 모서리가 크게 둥글고 bbox 75~84%. 반픽셀이 생겨 흐리다(mush24 0.21~0.45).
- **GNOME:** Nautilus는 실루엣 하나에 서랍 3개로 mush16 0.17. Calculator는 반복 버튼이 회색 덩어리가 된다(0.74). 작은 크기에는 별도 symbolic 아이콘이 필요하다.
- **Apple HIG:** 도형 수는 최소로, 배경은 단색이나 그라데이션으로 한다. 텍스트·사진·UI 복제를 하지 않는다. 직접 넣는 광택·베벨을 금지하고, 마스크는 시스템이 씌운다. 다크·틴트 변형에서도 특징을 유지한다.

| 대상 | mush32 | mush24 | mush16 |
|---|---|---|---|
| CBS | 0.15 | 0.21 | 0.25 |
| DB | 0.14 | 0.22 | 0.23 |
| Mitsubishi | 0.16 | 0.23 | 0.31 |
| Nautilus | 0.05 | 0.10 | 0.17 |
| AIGA | 0.18 | 0.55 | 0.72 |
| Calculator | 0.73 | 0.73 | 0.74 |
| 오륜 | 0.72 | 0.76 | 0.85 |

결론: **1색 면 실루엣이 축소에 가장 강하다.**

## 2. 교차 규칙(숫자)
**마크**
1. 요소는 1~3개, 색은 1~2색이다. 흑백 1색 버전이 먼저 성립해야 한다.
2. 획 두께는 하나다. 가장 얇은 부분은 7~10% 이상(16px에서도 1px이 남도록 최소 6.25%)이다.
3. 틈·음각은 4% 이상이다(2.3%가 하한).
4. 각도·비율 체계는 하나만 쓴다(30/60/90°, √3, 원만 중 하나).
5. 음각 공간을 두 번째 형상으로 설계한다.
6. 가로세로 비는 0.8~1.25다.
7. 잉크 면적은 25~60%다.
8. 대칭(IoU ≥ 0.95)이나 회전 대칭을 쓴다. 비대칭이면 무게중심 편차를 0.03 이하로 맞춘다.

**아이콘 세트**
9. 라이브 영역은 20/24(83%)다. 원형 20, 사각 18, 세로형 16×20으로 그려야 시각적 크기가 같다.
10. 획은 크기의 1/16~1/12로, 세트에 하나만 쓴다. 바깥 모서리 반경 = 획, 안쪽 반경 = 획/2.
11. 좌표는 그리드의 정수배로 잡는다. cap/join은 세트에 하나만 쓴다.

**앱 아이콘**
12. 배경은 1색이나 2색 그라데이션(명도 차 15 이하)이다. 전경 실루엣 1개, 디테일은 3종 이하다.
13. 전경은 폭 60~78%, 높이 70~82%를 차지한다. squircle n≈5로 마스크한다.
14. 그라데이션은 곡면에만 쓰고 빛은 하나다. 실루엣 밖 그림자, 텍스트(머리글자 1자는 예외)는 금지다.
15. **16px 합격선:** 1색 실루엣으로 무엇인지 말할 수 있어야 한다. 면 마크는 mush16 0.35 이하, mush32 0.4 이하다.

**UI 카드**
16. 모서리는 동심으로 맞춘다: 안쪽 반경 = 바깥 반경 − 패딩.
17. 아이콘 칩은 24 + 패딩 8 = 40, 배경은 아이콘 색의 10~15% 틴트다.
18. 간격은 4/8의 배수다. 카드 패딩 16~24, 아이콘과 텍스트 사이 12.

## 3. 코드 적용(Atelier DSL)
- **기본 단위:**
  - `U = size/24`, `STROKE = 2U`, `R_OUT = STROKE`, `R_IN = STROKE/2`, `PAD = 2U`
  - 좌표는 U의 정수배나 0.5배만 쓴다.
- **원-격자형:**
  - 반지름은 비율열 하나에서만 고른다(1, 0.618, 0.382).
  - 렌즈는 `group{clip:circle}`로 만든다.
  - 음각은 배경색 도형을 겹쳐 "파낸다".
- **각도 모듈형:**
  - `repeat{count:3, drot:120, origin}`으로 모듈을 돌린다.
  - 캔버스 비율은 모듈에서 유도한다(폭:높이 = 2:√3).
- **정사각+대각형:**
  - 테 두께 T = 0.14·size로 잡는다.
  - 사선은 가로 폭을 T/sinθ로 잡아 수직 두께를 T와 맞춘다.
- **앱 아이콘:**
  - `squircle{n:5}`에 그라데이션(명도 차 15 이하)을 깐다.
  - 전경 실루엣 하나를 광학 중심으로 1~2% 올린다.
  - 디테일은 같은 색상에서 명도만 ±20으로 바꾼다.
  - 바닥 프로필은 실루엣을 0.03 S 아래로 밀어 한 단계 어둡게 만든다.
- **광학 보정:**
  - 원은 사각형보다 2~3% 크게 그린다.
  - 뾰족한 끝은 기준선 밖으로 3~5% 내민다.
  - 수평획은 5~10% 얇게 한다.
  - 아래가 무거운 형태는 2~4% 위로 올린다.
- **검증:**
  1. `analyze.py`로 확인한다: 90% 면적을 덮는 색 2개 이하, 노탄 덩어리 5개 이하, 무게중심 편차 0.03 이하.
  2. 16/24/32px로 직접 렌더해 본다.
  3. 흑백 버전과 반전 버전에서도 성립하는지 본다.

## 4. 흔한 실수 → 규칙
| 실수 | 고치는 규칙 |
|---|---|
| 클립아트처럼 사물을 그대로 그림 | 실루엣 1개 + 특징 1개, 요소 3개 이하 |
| 그라데이션·광택으로 약한 형태를 덮음 | 흑백 1색에서 먼저 합격시킨다 |
| 획 두께·패딩이 제각각 | 상수 STROKE 하나와 20/24 키라인 |
| 임의 각도·반지름 | 각도 체계 1개, 비율열 1개 |
| 가로로 긴 마크(2:1 이상) | 0.8~1.25로 바꾸거나 심볼을 따로 만든다 |
| 틈 2% 미만, 선 5% 미만 | 틈 4% 이상, 면 마크 선 7~10% |
| 3색 이상 | 마크 1~2색, 앱 아이콘은 배경 + 전경 + 포인트 1 |
| 기하 중심에 그대로 둠 | 광학 중심 보정과 원 오버슈트 |
