# 피의 군주 — Atelier 제작 노트

원본 코드는 `bench2/atelier/src/`에 있습니다. 다시 빌드하려면 `node bench2/atelier/src/build.mjs`를 실행합니다.
6종이 같은 공통 팔레트(`palette.mjs`)를 씁니다: 피 5단 · 흑철 5단 · 뼈 4단 · 발광 3단.
색 수는 바닐라 jar 실측(아이템 7~13색, 갑옷 9~10색, 보스 18~24색)에 맞춰 절제했습니다.

| 항목 | 이름 / 콘셉트 | 반복에서 고친 것 |
|---|---|---|
| 무기 | **혈월낫**: 흑철 자루와 뼈 손잡이, 발광 혈석, 5마디 본 사슬로 휜 핏빛 날, 날 등의 뼈 가시. ModelEngine 규칙상 큐브는 회전시키지 않음(곡선은 본 회전으로) | v1 날이 가늘고 짧아 갈고리처럼 보임 → 넓고(8→2) 길게(33), 뼈 가시 추가. 아이콘 날을 초승달로 |
| 갑옷 | **혈철 군주 갑주**: T자 바이저 틈의 붉은 눈, 갈비뼈 흉갑과 혈석 심장, 뼈 테두리 견갑, 핏빛 태싯, 뼈 발끝 부츠. 텍스처 11색/9색 | 1px 체커 사슬이 멀리서 노이즈 → 2px 엇갈린 고리 |
| 기본 공격 | **3연타** — 1타 수평 베기(진홍) · 2타 역사선 올려베기(밝은 진홍, 더 빠름) · 3타 내려찍기(가장 큰 세로 궤적 → 바닥 충격파 + 혈창 3개 + 큰 비산) | 1타 평면이 3인칭에서 선처럼 보임 → 기울기 조정. 뷰어 틴트 색공간 수정 |
| 스킬 | **혈월 강림**: 발밑 피의 소용돌이 → 등 뒤에 핏빛 달 문양 → 360° 회전베기 → 혈창 6개가 원형으로 순차 분출 → 충격파 | 달 문양이 화면 밖 → 뷰어 프레이밍을 트랙 범위 기준으로 |
| 펫 | **혈박쥐 루비**: 둥근 핏빛 몸, 발광 눈, 두 마디 날개(몸 폭의 4배). idle·walk 날갯짓. 9색 | 회색 날개막이 흑철처럼 보임 → 진홍 막 + 뼈 손가락 |
| 보스 | **혈해의 거상**: 약 70유닛(플레이어 2.2배), 구부정한 거인. 갈비뼈 사이 발광 심장, 작은 뿔 해골, 땅에 닿는 긴 팔과 뼈 손톱, 손목의 흑철 족쇄(피의 군주에게 묶인 존재). hitbox 본 포함. idle·walk·attack(양손 내려찍기) | 밝은 살점이 위장무늬처럼 보임 → 어두운 살점·바랜 뼈. 심장이 갈비뼈에 가려지고 z-fighting → 크게, 한 층 뒤로 |
