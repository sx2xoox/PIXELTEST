# 비교 과제 2 결과: 피의 군주 — 일반 Claude vs Atelier

## 조건
- **브리프:** [BRIEF.md](BRIEF.md). Java 리소스팩 + ModelEngine 기준, 6종, 공통 파일 형식
- **일반 Claude:** 별도 에이전트. Atelier 엔진·스킬·문서는 참고하지 않고, 범용 도구(Python, Node, Playwright)는 자유롭게 썼다. 그래서 **스스로 큐브 렌더러와 미리보기를 만들어 반복 개선**했다. 최종본은 커밋 `ad9ad9d`에서 고정했다.
- **Atelier:** 엔진과 렌더 → 확인 → 수정 루프로 항목마다 2~3회 반복했다.
- **평가:** 같은 뷰어(.bbmodel 직접 해석)로 렌더한 이미지를 A/B 무작위 배정으로 섞고, 출처를 모르는 평가자 1명이 채점했다(항목당 50점).

## 해석
1. **품질 차이를 만든 핵심은 "결과를 보고 고치는 루프"다.**
   - 1차 비교에서는 일반 Claude가 한 번에 썼고, Atelier가 10전 10승했다.
   - 이번에는 일반 Claude도 스스로 렌더러를 만들어 같은 루프를 돌렸고, 미적 점수에서 앞섰다.
   - 즉 Claude가 디자인을 잘하게 만드는 1순위 요인은 엔진 라이브러리가 아니라 **시각 피드백 루프** 자체다.
2. **일반 Claude가 이긴 이유:** 캐릭터·서사 디테일을 더 많이 넣었다.
   - 예: 뼈가면 혈견, 낫을 든 보스, 망토, 피 덩굴, 가시 왕관
   - 큐브를 2.5배 많이 썼다.
   - 손으로 설계한 모티프가 Atelier의 절차적 재질(노이즈 기반)보다 '상품'처럼 보였다.
3. **Atelier가 이긴 곳:** 큰 덩어리 실루엣과 타이밍 설계가 중요한 곳이다(무기, 3연타 구분).
4. **Atelier가 확실히 앞선 곳은 미적 점수에 반영되지 않는 기술 정확성이다.**
   - ModelEngine 규칙 위반 0개, 색 절제, hitbox, 서버 틴트 가능한 이펙트를 갖췄다.
   - 일반 Claude 모델은 위반 47개라 그대로 ModelEngine에 넣으면 문제가 생긴다.
5. **두 세트 모두 출시 수준(항목당 40점)에는 못 미쳤다.**

## 한계
- 평가자가 1명이고, 같은 계열 모델이다.
- 지난 과제에서 같은 이미지에 대한 평가자 간 편차가 ±7점이었다. 그러니 무기(+1)·갑옷(-3)·3연타(+3) 차이는 편차 범위 안이다.
- 확실한 차이는 스킬·펫·보스(5~8점, 일반 Claude 우세)다.

## Atelier가 배울 것 → 다음 개선 과제
- **절차적 재질 의존 줄이기:** 큰 면에는 방향이 있는 손 설계 패턴(근육결, 핏줄 방향, 판금 이음새, 관절 음영)을 쓴다. 노이즈 얼룩은 '위장무늬'로 읽힌다(보스·펫에서 반복 지적).
- **캐릭터에 서사 소품 넣기:** 보스가 직업 무기를 든다, 가면, 망토, 넝마 끝처럼 세계관을 잇는 요소. 디테일 예산(큐브 수)을 더 쓴다.
- **이펙트 연출 곡선:** 시작 → 축적 → 절정 → **페이드 아웃**. 정적인 구간을 없애고, 끝이 뚝 끊기지 않게 한다. 비평기에 "마지막 프레임 페이드 여부"와 "정적 구간 길이" 검사를 추가한다.
- **원시 도형 그대로 쓰지 않기:** 가시는 깎인 면이 있는 형태로, 검기는 2~3단 팔레트로 끝이 흩어지게 만든다.
- **날개막·투명 면:** 빈 틀로 보이지 않게 막을 채우거나 반투명 처리한다.
- **반대로 일반 Claude 방식에 없는 것:** ModelEngine·바닐라 규칙 검사, 색 예산, 틴트 가능한 이펙트, 원본 형식 왕복 검증. 이것들이 Atelier의 실질적 가치다.
